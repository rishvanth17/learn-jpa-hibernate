# Job Portal REST API

A simple Job Portal REST API built using Spring Boot, Spring Data JPA, Hibernate, and MySQL.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- REST API
- Postman

## Features

- Add a new job
- Get all jobs
- Get a job by ID
- Update job details
- Delete a job
- MySQL database integration
- CRUD operations using Spring Data JPA
